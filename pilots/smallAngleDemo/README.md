# Pilot Transformation for Small Angle Approximation Demonstration

## Small Angle Approximation Demonstration

This tool illustrates an angle defined by the distance to and size of an object. It uses the small angle approximation to determine the angle in arcseconds. Primary components are the equation for the angle as a function of object distance and size, which updates in real time; illustration of angle using viewer and beach ball; number box, slider, and preset button values for both distance and size (diameter).
