# KL-UNL Simulation Foundation

## Foundation Files
Foundation files are designed to be referenced by an HTML file within the workspace for a simulation.
They provide a uniform masthead and project style, and set up MathJax for displayed equations.
    * Masthead:         kl-unl-masthead.js
    * Masthead:         kl-unl-masthead.json
    * Equations:        kl-unl-mathjax.js
    * Utilities:        kl-unl-utils.js
    * Celestial Sphere: kl-unl-csphere.js
    * Style:     ../css/kl-unl.css
    * Icon:      ../images/klunl_favicon_32.png
    * Icon:      ../images/klunl_favicon_180.png
