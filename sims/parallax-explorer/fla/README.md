# Original Flash source (decompiled)

This folder holds the original **Parallax Explorer** Flash sim and its decompiled
assets — the ground-truth reference the accessible HTML5 port (in the repository
root) was built from. Nothing here is used at runtime by the HTML5 sim.

- `parallaxExplorer009.fla`, `parallaxExplorer009.swf` — the original Flash files
- `scripts/` — decompiled ActionScript (AS1)
- `shapes/`, `sprites/`, `morphshapes/`, `frames/`, `images/`, `movies/` — exported art
- `fonts/`, `texts/`, `symbolClass/` — exported fonts, text strings, and symbol linkage
- `foundation/` — the KL-UNL foundation files as originally provided
- `Capture.PNG` — screenshot of the running original (layout reference)

See the port's [CONVERSION_NOTES.md](../CONVERSION_NOTES.md) for how these map to
the HTML5 implementation.
